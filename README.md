# 📊 VolatiRisk - Análise e Classificação de Risco de Ativos Financeiros

O **VolatiRisk** é um projeto em **Python** que analisa e classifica o risco de ativos financeiros com base na sua **volatilidade**. Utilizando bibliotecas como **Pandas, NumPy, Seaborn e Matplotlib**, o projeto processa dados históricos, calcula métricas estatísticas e gera visualizações para auxiliar na **tomada de decisão**.

## 🚀 Funcionalidades

- 📈 **Cálculo de volatilidade** de ativos financeiros.
- 📊 **Geração de gráficos e visualizações** para análise de risco.
- 📉 **Classificação de risco** dos ativos com base em métricas estatísticas.
- 🤖 **Modelo supervisionado** para categorizar o nível de risco.

## 🛠 Tecnologias Utilizadas

- **Python** 🐍
- **Pandas** – Manipulação de dados
- **NumPy** – Cálculos matemáticos e estatísticos
- **Seaborn & Matplotlib** – Visualização de dados
- **Scikit-Learn** – Modelagem preditiva
